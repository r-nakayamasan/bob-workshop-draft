## 1. はじめに

### Java UI Modernization ワークフローとは

Java UI Modernization ワークフローは、IBM Bob 内でレガシー Java Web UI をモダナイズするための、AI アシスト型のガイドプロセスです。このラボでは `snapC-ui-mod`（Struts/JSP サーバーサイドレンダリングで構築された Simple Pharmacy アプリケーション）にワークフローを適用します。

ワークフローの対象範囲：

- **分析**: 既存の Struts/JSP コードベースを調査（コンポーネント、ルーティング、状態管理、データ、レイアウトパターン）
- **計画**: モダナイゼーション計画を作成し、ターゲット状態のオプションを提示
- **コード生成**: 選択したターゲット状態の UI を生成し、既存バックエンドと統合
- **検証**: モダナイズされた UI を稼働中のバックエンドに対してテスト

### このラボについて

IBM Bob を使って `snapC-ui-mod` アプリケーションに Java UI Modernization ワークフローを実行します。

| 項目 | 内容 |
|------|------|
| **開始状態** | Struts/JSP サーバーサイドレンダリング |

ワークフロー中に、Bob がアプリケーションを分析して 1 つ以上のターゲット状態オプションを提案します。オプションを確認して実装するものを選択してください。

### 学習目標

このラボを完了すると、次のことができるようになります。

- Bob で Java UI Modernization ワークフローを開始・操作できる
- Bob にレガシー Struts/JSP アプリケーションを分析させ、ターゲット状態オプションを確認できる
- 選択したモダナイズ UI の生成・改善を Bob にガイドできる
- モダナイズされたアプリケーションをエンドツーエンドで実行・テストできる

## 3. Java UI Modernization ワークフローの開始

### 0. スナップショットを取得する

Bob に以下をお願いしてください。

> 以下の URL から Lab 3 用のスナップショットをダウンロードして展開してください。
>
> `https://raw.githubusercontent.com/r-nakayamasan/bob-workshop-draft/main/snapshots/snapC-ui-mod.zip`
>
> ダウンロードして `~/lab-workspace/` に展開してください。

Bob が自動で以下のコマンドを実行します（Mac/Windows どちらでも動作します）：

```bash
# ダウンロード
curl -L -o snapC.zip "https://raw.githubusercontent.com/r-nakayamasan/bob-workshop-draft/main/snapshots/snapC-ui-mod.zip"

# 展開
python -m zipfile -e snapC.zip ./lab-workspace/
```

!!! tip "作業フォルダの場所"
    展開先は任意の場所で構いません。`~/lab-workspace/` の部分はお好みのパスに変更してください。

### ワークスペースを開く

1. 展開した **`snapC-ui-mod/`** フォルダを Bob のアクティブなワークスペースとして開く
2. Bob チャットインターフェースを開く

### Agent モードに切り替える

Java UI Modernization ワークフローは Bob の **Agent モード**で実行されます。Agent モードでは以下が可能です。

- 複数ファイルの読み書き操作
- 複雑なマルチステップのワークフロー実行
- レガシー Java UI パターンとモダン UI モダナイゼーションに関する深い知識の活用

**Agent モードへの切り替え**:

1. Bob チャットウィンドウ下部のモードインジケーターをクリック
2. ドロップダウンから **Agent** を選択

### ワークフローのトリガー

設定ギアの近くにある再生ボタン `(▶︎)` を押して、Java Modernization ワークフローの **Start** を押します。

または、Bob チャットウィンドウで以下のように入力してもワークフローを開始できます。

```
この Java アプリケーションの UI をモダナイズしたいです。Java UI Modernization ワークフローを実行してください。
```

Bob が Java UI Modernization ワークフローを開始し、分析フェーズから進みます。

## 4. ワークフローのステップバイステップ

### ステップ 1：プロジェクトを分析する

プロジェクトパスが Java アプリを指していることを確認して **Continue** をクリックします。Bob がアプリの初期ビルドを実行して、開始状態が正常に動作することを確認します。

---

### ステップ 2：`UI Modernization` を選択する

UI Modernization タイプを選択します。Git Flow の有効/無効も選択できます。有効にすると、Bob がこのモダナイゼーション用に新しい Git ブランチを自動作成します。**Continue** をクリックします。

!!! note
    Git Flow を有効にすると、Bob はワークフローの進行に合わせて自動的に Git コミットを行います。

Bob がアプリケーションのアーキテクチャを分析し、サブタスクでドキュメントを作成します。

---

### ステップ 3：モダナイゼーションスタックを選択する

Bob がどのスタックにモダナイズするか尋ねます。このラボでは以下を選択してください。

| 設定 | 値 |
|------|-----|
| **フロントエンドフレームワーク** | `React` |
| **フロントエンドデザインシステム** | `Material UI` |

| **バックエンドフレームワーク** | `Jakarta EE style Rest Services` |

Bob がサブタスクでバックエンド移行を開始し、To-Do リストで進捗を管理します。Bob ウィンドウ上部の To-Do リストバーをクリックすると、リストを展開・折りたたみできます。

## 5. トラブルシューティング

### Bob のターミナルで Java バージョンが期待と異なる

**症状**: Bob のターミナルで `java -version` が予期しないバージョンを表示する

**対処法**: Bob のターミナルで以下を実行してください。

```bash
sdk use java 21.0.11-zulu
```

`sdk use` はシェルスコープのため、ターミナルタブや Bob が独立して開くターミナルには適用されません。各シェルで個別に実行する必要があります。

---

### バックエンドのビルドエラー

**症状**: `mvn clean package` が失敗する

**対処法**: エラーの完全な出力を Bob チャットに貼り付けてください。Bob が自律的に修正します。

---

### フロントエンドの npm エラー

**症状**: `npm run dev` でエラーが発生する

**対処法**: エラー内容を Bob チャットに貼り付けてデバッグしてもらいます。

```bash
# node_modules をクリーンインストールする場合
cd frontend
rm -rf node_modules package-lock.json
npm install
```

## 6. まとめ

Lab 3（Java UI Modernization ワークフロー）を Simple Pharmacy アプリケーションに適用して完了しました。

- ✅ IBM Bob で Java UI Modernization ワークフローを開始する
- ✅ Bob が提案したターゲット状態オプションを確認して選択する
- ✅ 選択したターゲット状態のモダナイズ UI を Bob にガイドして生成・検証する

### 重要なポイント

1. **Java UI Modernization ワークフロー**: Bob のガイド付きワークフローで、最小限の手動設定でレガシー Java UI をモダナイズできる
2. **ターゲット状態の選択**: ワークフローが複数の UI モダナイゼーションオプションを提示し、ユーザーが評価して選択できる
3. **段階的なアプローチ**: 分析 → 計画 → 生成 → 検証という順序で、予測可能でレビュー可能な結果を生む
4. **バックエンドの継続性**: 既存の Liberty バックエンドが検証中もモダナイズ UI をサポートし続ける
5. **インタラクティブなガイド**: ワークフロー全体を通じてユーザーが Bob をガイドして生成結果を改善できる

### 次のステップ（オプション）

追加時間がある場合や、さらに探求したい場合：

**生成された UI の最適化**:
```
選択したターゲット状態向けに生成された UI を最適化してください。
```

**コード品質のレビュー**:
```
移行されたコードのアーキテクチャ、保守性、エラーハンドリング、コード構成、ドキュメントの完成度をレビューしてください。
```

**モダナイゼーションサマリーの作成**:
```
モダナイズされた内容、選択したターゲット状態、主要なアーキテクチャの変更点、既知の問題、次のステップを含む MIGRATION_SUMMARY.md を作成してください。
```
