# LAB2 - 機能開発
![LAB2 Header](../assets/images/04_lab2/lab2_header.png)

LAB1 で作成したサイトをさらにブラッシュアップし、4 つの機能を新たに追加します。


![Additional Features](../assets/images/04_lab2/additional_features.png)

- **Func1: Bob 画像素材の挿入** ⭐ - `bob.svg` を FAQ サイト左上に挿入
- **Func2: Bob 製品サイト URL の埋め込み** ⭐ - 画像クリックで製品サイト（<https://www.ibm.com/products/bob>）へ遷移
- **Func3: テーマカラーの変更** ⭐⭐ - Bob のイメージカラー（青〜紫のグラデーション）へ変更
- **Func4: ダークモードテーマの追加** ⭐⭐⭐ - ライト／ダークモード切り替えボタンを追加

!!! note "注意"
    LAB1 ですでに追加済みの機能はスキップしてください。

---

## セッションの切り替え

Bobcoin の横にある **❌ ボタン** を押して、セッションを切り替えます。

<img src="../assets/images/04_lab2/session_switch_v2.png" alt="Bobcoin 横の ❌ ボタンでセッション切り替え">

**確認ポイント:**

- LAB1 の履歴がチャット画面下部に表示される
- 新しいチャット画面が開く


## Prompt の入力と実装計画の立案

### 1. Prompt の入力

**Plan モード** を選択し、機能追加のための Prompt を入力します。`PROMPT2.md` や以下の例を参考に、Prompt を作成してみてください。

**Prompt の例:**

```
作成したFAQサイトに以下の機能をつけてください
1. サイト左上にBobの画像を挿入（ @/bob.svg ）
2. 1の画像にリンクを挿入（ https://www.ibm.com/products/bob ）
3. サイトテーマカラーをBob画像のカラーに変更（ @/bob.svg ）
4. ダークテーマの追加
```

<img src="../assets/images/04_lab2/prompt_input_v2.png" alt="Plan モードで Prompt を入力">

### 2. スキルのロードと既存コードの調査

Prompt を送信すると、Bob が `create-plan` スキルを読み込み、調査を開始します。

<img src="../assets/images/04_lab2/skill_load_v2.jpg" alt="create-plan スキルの読み込みと調査開始">

Bob は独立した **サブエージェント**（独自のコンテキストウィンドウを持つエージェント）を呼び出し、既存コードベースを調査します。サブエージェントは調査結果のみを親エージェントに返すため、メインコンテキストの汚染を防ぐ役割を担います。

<img src="../assets/images/04_lab2/subagent_scan_v2.png" alt="サブエージェントによる既存コードベースの調査">

サブエージェントの実行結果は展開して確認できます。サブエージェントに渡したプロンプトと調査結果の両方を見ることができます。

<img src="../assets/images/04_lab2/subagent_details_v2.png" alt="サブエージェントのプロンプトと調査結果の詳細">

### 3. 設計選択肢への回答

調査が完了すると、Bob が今回の実装方式について選択肢を提示します（テーマカラーやダークテーマの設計方針など）。希望する選択肢をクリックして回答します。

<img src="../assets/images/04_lab2/design_choice_v2.png" alt="テーマカラー・ダークテーマの設計選択肢">

### 4. 仕様書と設計書の自動生成

回答後、「フォローアップ質問しました」というメッセージが表示され、Bob が設計内容をもとに `specs/` フォルダに **仕様書** と **設計書** の 2 ファイルを自動生成します。

<img src="../assets/images/04_lab2/spec_generation_v2.png" alt="specs/ フォルダへの仕様書・設計書の自動生成">

### 5. 仕様書・設計書の確認

生成された仕様書と設計書の内容を確認します。

<img src="../assets/images/04_lab2/spec_review_v2.png" alt="生成された仕様書・設計書の確認">

### 6. 実装計画の確認と承認

仕様書生成後、実装計画の全体像がチャット画面に表示されます。

<img src="../assets/images/04_lab2/plan_overview_v2.png" alt="実装計画の全体像">

設計方針に問題がなければ、計画を承認します。承認すると、Bob が **Agent モード** に切り替わり、実装を開始します。

<img src="../assets/images/04_lab2/agent_mode_switch_v2.png" alt="Agent モードへ切り替えて実装開始">


## コード開発

承認後、Bob がコード修正を進めます。この工程では基本的にユーザー操作は不要です。Bob のコード生成を見守ります。

<img src="../assets/images/04_lab2/implementation_progress_v2.png" alt="コード生成中の進捗">

生成が完了すると、変更内容のサマリーが表示されます。

<img src="../assets/images/04_lab2/implementation_summary_v2.jpg" alt="コード生成完了時のサマリー">


## サイトの確認

### 1. サイトを開く

コード修正のタスクが完了すると、テスト工程に移ります。Bob がサイトを開くコマンドの承認を求めるので、承認します。

<img src="../assets/images/04_lab2/open_browser_v2.png" alt="サイトを開くコマンドの承認">

### 2. 追加機能の動作確認

作成されたサイトで、追加した機能が正しく反映されているか確認します。

**Func1: Bob 画像の挿入**

- `bob.svg` が左上に表示されている
- 適切なサイズで表示されている
- レイアウトが崩れていない

**Func2: 製品サイトへのリンク**

- 画像をクリックできる
- 新しいタブで製品サイトが開く

**Func3: テーマカラーの変更**

- Bob のイメージカラー（青〜紫のグラデーション）が適用されている
- 全体的に統一感がある

**Func4: ダークモード**

- 切り替えボタンが表示されている
- ボタンをクリックでライト／ダークが切り替わる

!!! note "動作に問題があるときは"
    サイトがエラーになっている場合は、Bob に状況を伝えて修正を依頼してください。

    **対処の流れ:**

    1. エラーメッセージを確認する
    2. Bob にエラー内容を伝える
    3. Bob の修正提案を確認する
    4. 修正を適用する
    5. 再度テストする

**完了条件:**

- Bob 画像が正しく表示される
- 画像リンクが動作する
- テーマカラーが適用されている
- ダークモードが正常に動作する
- すべての既存機能が維持されている

余裕があれば、LAB3 にも挑戦してみましょう。
